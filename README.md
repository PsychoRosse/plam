# Plam

A lightweight Rust library for mathematical operations in 2D and 3D graphics.

## Features

- Vectors: `Vec2`, `Vec3`, `Vec4`
- Quaternion rotations: `Quat`
- 4×4 matrices: `Mat4`
- Vector and matrix arithmetic
- Translation, rotation, and scaling transformations
- Perspective projection
- Serialization and deserialization

## Design

The library provides mathematical types and operations for graphics and geometry, with a focus on a simple and consistent API.

Angles are expressed in degrees.
